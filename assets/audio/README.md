# 互动音效

这七个 WAV 为本项目本地合成的原创音效，无外部采样或运行时网络依赖。

| 文件 | 触发 |
| --- | --- |
| box.wav | 顶箱，包括已使用的箱子 |
| brick.wav | 砖块破碎 |
| acorn.wav | 拾取橡果或获得箱子橡果奖励 |
| stomp.wav | 踩敌反弹 |
| shield_break.wav | 护盾抵挡伤害并破裂 |
| shield_pickup.wav | 获得护盾 |
| hit.wav | 无护盾时受伤 |

格式：44.1kHz、16 位单声道 PCM，长度 0.16–0.40 秒，游戏播放音量为 32%。
使用 `python scripts/generate_feedback_audio.py` 可重复生成。同一物理帧的同类声音合并播放；暂停时暂停声音，重开时停止残留声音；无音频设备时继续显示动画。

视觉效果由 `ai_platformer/rendering/feedback.py` 消费实际游戏事件：箱子上移最多 8px 后归位；砖块碎成八片；橡果先向上弹再飞到 HUD，抵达后计数栏闪环；踩敌带压扁和冲击环；护盾光罩碎裂成十片蓝色碎片。它们均不改变碰撞盒。HUD 数量包含地面拾取及箱子奖励，数字在奖励生效时立即更新。
